# Nvim configuration

## Introduction

This is a fork of [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim)
customized for my workflow and needs.
It is very much a work in progress as I'm a novice to neovim.
Right now I'm focusing on dotnet framework project development, testing and debugging,
where the heavy lifting seems to have been done by [easy-dotnet.nvim](https://github.com/GustavEikaas/easy-dotnet.nvim)
(which I'm currently testing out).
